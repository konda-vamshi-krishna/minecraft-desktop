## 2026-11-08 - Crosshair Visibility Contrast
**Learning:** Static 2D UI elements like crosshairs can easily blend into bright backgrounds (like sky or snow in Minecraft), making them hard to see and degrading UX/accessibility.
**Action:** Always add a contrasting outline or drop shadow (e.g., drawing a slightly larger, semi-transparent black shape behind the primary element) when rendering static UI over dynamic 3D environments.
