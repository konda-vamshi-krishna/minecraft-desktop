## 2026-10-27 - Crosshair Contrast and Keyboard Shortcuts
**Learning:** Adding a 1-pixel shadow offset (`+1, +1`) behind UI elements drawn directly over 3D game worlds significantly improves contrast and visibility, preventing them from blending into bright textures like sky or snow blocks.
**Action:** Consistently use shadows or contrasting outlines for persistent HUD elements overlaid on the 3D scene.

## 2026-10-27 - Keyboard Shortcuts in Hotbar
**Learning:** Displaying shortcut keys directly on action bar or hotbar slots significantly improves user discovery and keyboard navigation accessibility.
**Action:** When adding fixed-slot UI, add small text indicators for the corresponding keyboard shortcuts.
