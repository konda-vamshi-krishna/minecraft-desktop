## 2024-05-24 - Keyboard Shortcut Hints in Hotbar
**Learning:** Adding explicit keyboard shortcuts (1-9) directly on the UI elements (hotbar slots) bridges the gap between discoverability and power-user efficiency. Even if shortcuts are in the help text, in-context cues reduce cognitive load significantly.
**Action:** Always consider adding subtle, in-context keyboard shortcut hints to frequently used actions or inventory slots rather than relying solely on a separate help menu or overlay.
