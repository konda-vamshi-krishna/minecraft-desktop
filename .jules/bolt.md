## 2026-11-09 - Mesher optimization bottlenecked by bounds checking and function call overheads
**Learning:** The greedy voxel mesher (`src/world/mesher.c`) is heavily bottlenecked by bounds checking and function call overheads in its innermost loops, specifically inside `Mesher_SampleVoxel`. By leveraging `__builtin_expect`, casting signed integers to unsigned integers to halve boundary branch conditions, and using direct indexing `ChunkVoxelIndex`, a fast path can be created to optimize interior block access.
**Action:** When working on block traversals, always create a static inline version using `__builtin_expect` to fast track indices that sit well within bounds (`< CHUNK_WIDTH - 1`, etc) which completely removes overhead for the majority of sampling queries. Never hardcode magic numbers for strides (e.g. `256`, `4096`), always use the defined index calculations.
