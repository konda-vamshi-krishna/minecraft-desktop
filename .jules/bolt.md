## 2026-11-08 - Greedy Mesher Inner Loop Bounds
**Learning:** The greedy mesher in `src/world/mesher.c` spends the vast majority of its time evaluating the comparison mask using `Mesher_SampleVoxel`. `Mesher_SampleVoxel` contains branch-heavy bounds-checking logic for boundary neighbor meshing. However, for interior slices (`0 <= x[d] < dLimit - 1`), both slices are guaranteed to be within chunk bounds, allowing direct `chunk->voxels` array accesses without any boundary checks.
**Action:** Always seek to split nested loops traversing chunk volumes into a bounded interior "fast path" (using direct array indices) and a "slow path" (for chunk boundaries) to eliminate branch mispredictions and bounds checking overheads on >88% of voxel operations. Furthermore, moving the sample and opaque functions into the header as `static inline` removes function call overhead.
