## 1. Universal Distribution & The "Zero Friction" Mandate

The primary metric of success for this distribution pipeline is **Zero External Friction**:
1. **Zero Runtime Installers:** No JRE, no Python runtime, no .NET framework, no Visual C++ Redistributables (`VCRUNTIME140.dll` / `MSVCP140.dll` missing errors are strictly forbidden).
2. **Zero Operating System Mutation:** No Windows Registry keys modified or created. No `%APPDATA%` or `~/.local/share` pollution without explicit portable fallback. No administrative elevation (UAC prompt) requested.
3. **True USB-Stick Portability:** A user can copy the game folder onto an exFAT/FAT32 USB thumb drive, move between different Windows/Linux/macOS machines, and launch their world with progress stored strictly inside `./saves` relative to the executable.

## 2. Cold-Start Verification & Binary Integrity Contract

Every artifact generated by the CI pipeline must pass three non-negotiable verification gates before publication.

### 2.1. Dynamic Linker Audit (Zero DLL Dependencies)

A binary fails verification if it depends on any non-standard or third-party dynamic libraries.

#### Windows PE (`minecraft.exe`)
* **Allowed Imports (Guaranteed in all Windows installations since Windows 7 SP1):**
  - `KERNEL32.dll` (Base Win32 APIs)
  - `USER32.dll` (Windowing, raw input, message pump)
  - `GDI32.dll` (Device context, pixel format selection)
  - `OPENGL32.dll` (OpenGL ICD loader)
  - `WINMM.dll` (High-resolution multimedia timer: `timeBeginPeriod`)
  - `SHELL32.dll` (Command-line arguments, shell path helpers)
* **Banned Imports:**
  - `VCRUNTIME140.dll`, `MSVCP140.dll` (Banned: Must statically link C runtime via `/MT` or GCC MinGW `-static-libgcc -static`)
  - `D3DCompiler_*.dll`, `DXGI.dll` (Banned: OpenGL 3.3 Core only)
  - Third-party DLLs: `raylib.dll`, `glfw3.dll` (Banned: Must be statically compiled into the executable)

#### Linux ELF (`minecraft-linux-x64`)
* **Glibc Minimum Baseline:** Compiled on Ubuntu 20.04 (`glibc 2.31`) or statically linked against `musl`. An ELF binary compiled against a bleeding-edge glibc (e.g. 2.38+) will crash with `version 'GLIBC_2.38' not found` on Debian Stable or Enterprise Linux.
* **X11 / Wayland / OpenGL Dynamic Resolvers:** Dynamic linking restricted strictly to `libc.so.6`, `libm.so.6`, `libpthread.so.0`, `libdl.so.2`, `libGL.so.1`, and `libX11.so.6`.

#### macOS Universal Binary (`minecraft-macos`)
* **Dual Architecture Fat Binary:** Merged via `lipo` containing native slices for both `x86_64` (Intel Macs) and `arm64` (Apple Silicon M1/M2/M3/M4).
* **Target Deployment SDK:** `MACOSX_DEPLOYMENT_TARGET=11.0`.

## 3. Portable Storage & Path Resolution Engine

When a user double-clicks an executable from a desktop shortcut or secondary drive, the Operating System's current working directory (CWD) is frequently set to the user's home folder (`C:\Users\<Name>` or `/home/<user>`), **NOT** the directory containing the binary.

The engine must explicitly resolve its absolute base directory on launch.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#if defined(_WIN32)
    #include <windows.h>
#elif defined(__linux__)
    #include <unistd.h>
    #include <linux/limits.h>
#elif defined(__APPLE__)
    #include <mach-o/dyld.h>
#endif

static char g_BasePath[1024] = {0};

void InitPortablePaths(void) {
#if defined(_WIN32)
    wchar_t widePath[MAX_PATH];
    GetModuleFileNameW(NULL, widePath, MAX_PATH);
    // Convert wide char to UTF-8
    WideCharToMultiByte(CP_UTF8, 0, widePath, -1, g_BasePath, sizeof(g_BasePath), NULL, NULL);
    // Strip executable name
    char* lastSlash = strrchr(g_BasePath, '\\');
    if (lastSlash) *(lastSlash + 1) = '\0';
    SetCurrentDirectoryA(g_BasePath);
#elif defined(__linux__)
    char procPath[PATH_MAX];
    ssize_t len = readlink("/proc/self/exe", procPath, sizeof(procPath) - 1);
    if (len != -1) {
        procPath[len] = '\0';
        char* lastSlash = strrchr(procPath, '/');
        if (lastSlash) *(lastSlash + 1) = '\0';
        strncpy(g_BasePath, procPath, sizeof(g_BasePath) - 1);
        chdir(g_BasePath);
    }
#elif defined(__APPLE__)
    char applePath[1024];
    uint32_t size = sizeof(applePath);
    if (_NSGetExecutablePath(applePath, &size) == 0) {
        char* lastSlash = strrchr(applePath, '/');
        if (lastSlash) *(lastSlash + 1) = '\0';
        strncpy(g_BasePath, applePath, sizeof(g_BasePath) - 1);
        chdir(g_BasePath);
    }
#endif
}
```

### 3.1. Save Directory Storage Policy
* Save data is written exclusively to `<BasePath>/saves/`.
* If `<BasePath>` is read-only (e.g. read-only optical disc or locked network mount), the engine gracefully issues an in-game warning and falls back to a non-destructive OS temp cache, rather than crashing with an unhandled file access exception.

## 4. Anti-Virus (AV) Heuristic False-Positive Mitigation

Self-extracting packers (such as UPX or PyInstaller bootloaders) trigger heuristic alerts (`Trojan.Generic`, `ML.Attribute.HighConfidence`) in Microsoft Defender and VirusTotal engines due to entropy packing and runtime memory unmapping.

### 4.1. Rules for Clean AV Clearance
1. **Strict Ban on Binary Packers:** UPX, Petite, and custom runtime unpackers are **FORBIDDEN**. The executable must be raw PE/ELF machine code.
2. **Standard Compiler Optimizations:** Use `-O3` with `-flto` (Link-Time Optimization) and standard section headers (`.text`, `.rdata`, `.data`, `.rsrc`).
3. **Embedded PE Manifest & Version Information:** Unsigned executables without company name, file description, copyright, and manifest flags are down-ranked by Windows SmartScreen. We inject a standard Win32 resource script (`res/resource.rc`):

```rc
// res/resource.rc - Win32 Metadata and Manifest Embedder
101 ICON "res/icon.ico"

1 VERSIONINFO
FILEVERSION     1,0,0,0
PRODUCTVERSION  1,0,0,0
FILEOS          0x40004
FILETYPE        0x1
BEGIN
    BLOCK "StringFileInfo"
    BEGIN
        BLOCK "040904b0"
        BEGIN
            VALUE "CompanyName",      "Minecraft Desktop Open Source Team"
            VALUE "FileDescription",  "Minecraft Desktop - Universal Native Voxel Engine"
            VALUE "FileVersion",      "1.0.0.0"
            VALUE "InternalName",     "minecraft-desktop"
            VALUE "LegalCopyright",   "Copyright (C) 2026"
            VALUE "OriginalFilename", "minecraft.exe"
            VALUE "ProductName",      "Minecraft Desktop"
            VALUE "ProductVersion",   "1.0.0.0"
```

## 5. GitHub Actions CI/CD Matrix Pipeline

Below is the complete, production-hardened GitHub Actions workflow file: `.github/workflows/build_and_release.yml`.

```yaml
name: Build & Universal Distribution Release

on:
  push:
    branches: [ "main" ]
    tags: [ "v*" ]
  pull_request:
    branches: [ "main" ]

jobs:
  build:
    name: Build (${{ matrix.target-name }})
    runs-on: ${{ matrix.os }}
    strategy:
      fail-fast: false
      matrix:
        include:
          # Windows MSVC Build (Statically Linked CRT)
          - os: windows-latest
            target-name: windows-x64
            artifact-name: minecraft-desktop-windows-x64.zip
            executable-name: minecraft.exe

          # Linux Portable ELF (Built on Ubuntu 20.04 for glibc 2.31 compatibility)
          - os: ubuntu-20.04
            target-name: linux-x64
            artifact-name: minecraft-desktop-linux-x64.tar.gz
            executable-name: minecraft

          # macOS Universal 2 (Intel x86_64 + Apple Silicon arm64)
          - os: macos-latest
            target-name: macos-universal
            artifact-name: minecraft-desktop-macos-universal.zip
            executable-name: minecraft

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          submodules: recursive

      # -------------------------------------------------------------
      # WINDOWS BUILD
      # -------------------------------------------------------------
      - name: Setup Windows Environment & Build
        if: runner.os == 'Windows'
        shell: bash
        run: |
          mkdir -p build
          # Compile resource script containing icon and manifest
          windres res/resource.rc -O coff -o build/resource.res || echo "No windres found, skipping rc"
          
          # Compile engine with static Raylib and static C runtime
          gcc -O3 -flto -std=c99 -Wall \
              -DPLATFORM_DESKTOP \
              -Iinclude -Isrc \
              src/*.c \
              build/resource.res \
              -o build/minecraft.exe \
              -Llib/windows -lraylib \
              -lopengl32 -lgdi32 -lwinmm -luser32 -lshell32 \
              -static-libgcc -static -s

          # Audit dynamic links - Verify zero forbidden DLLs
          dumpbin /dependents build/minecraft.exe || objdump -p build/minecraft.exe | grep "DLL Name"

      # -------------------------------------------------------------
      # LINUX BUILD
      # -------------------------------------------------------------
      - name: Setup Linux Dependencies & Build
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update
          sudo apt-get install -y libasound2-dev libx11-dev libxrandr-dev libxi-dev \
                                  libgl1-mesa-dev libglu1-mesa-dev libxcursor-dev \
                                  libxinerama-dev libwayland-dev libxkbcommon-dev
          mkdir -p build
          gcc -O3 -flto -std=c99 -Wall \
              -DPLATFORM_DESKTOP \
              -Iinclude -Isrc \
              src/*.c \
              -o build/minecraft \
              -Llib/linux -lraylib \
              -lGL -lm -lpthread -ldl -lrt -lX11 \
              -s

          # Verify dynamic loader dependencies
          ldd build/minecraft

      # -------------------------------------------------------------
      # MACOS UNIVERSAL BUILD
      # -------------------------------------------------------------
      - name: Build macOS Universal Binary
        if: runner.os == 'macOS'
        run: |
          mkdir -p build
          # Compile x86_64 slice
          clang -O3 -flto -std=c99 -target x86_64-apple-macos11.0 \
                -DPLATFORM_DESKTOP -Iinclude -Isrc src/*.c \
                -o build/minecraft_x86_64 \
                -Llib/macos -lraylib_x86_64 \
                -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo

          # Compile arm64 slice (Apple Silicon)
          clang -O3 -flto -std=c99 -target arm64-apple-macos11.0 \
                -DPLATFORM_DESKTOP -Iinclude -Isrc src/*.c \
                -o build/minecraft_arm64 \
                -Llib/macos -lraylib_arm64 \
                -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo

          # Merge into single Universal 2 Fat Binary
          lipo -create -output build/minecraft build/minecraft_x86_64 build/minecraft_arm64
          rm build/minecraft_x86_64 build/minecraft_arm64
          strip -x build/minecraft

          # Audit binary architectures and linkage
          lipo -info build/minecraft
          otool -L build/minecraft

      # -------------------------------------------------------------
      # PACKAGE ZERO-INSTALLER ARCHIVE
      # -------------------------------------------------------------
      - name: Assemble Release Package
        shell: bash
        run: |
          mkdir -p dist/minecraft-desktop
          cp build/${{ matrix.executable-name }} dist/minecraft-desktop/
          cp -r assets dist/minecraft-desktop/
          mkdir -p dist/minecraft-desktop/saves
          
          cat << 'EOF' > dist/minecraft-desktop/README.txt
          ==================================================
          MINECRAFT DESKTOP - UNIVERSAL 1-CLICK EDITION
          ==================================================
          1. Extract this entire folder anywhere you want.
          2. Double-click the executable to launch.
          3. Save files and settings will be stored in ./saves/
          4. Zero installation or internet required. Enjoy!
          ==================================================
          EOF

          cd dist
          if [ "${{ runner.os }}" == "Windows" ]; then
            7z a -tzip ../${{ matrix.artifact-name }} minecraft-desktop/
          elif [ "${{ runner.os }}" == "Linux" ]; then
            tar -czvf ../${{ matrix.artifact-name }} minecraft-desktop/
          elif [ "${{ runner.os }}" == "macOS" ]; then
            zip -r ../${{ matrix.artifact-name }} minecraft-desktop/
          fi
          cd ..

      - name: Upload Build Artifacts
        uses: actions/upload-artifact@v4
        with:
          name: ${{ matrix.target-name }}
          path: ${{ matrix.artifact-name }}

  # -----------------------------------------------------------------
  # RELEASE JOB: PUBLISH TO GITHUB RELEASES ON TAG
  # -----------------------------------------------------------------
  release:
    name: Publish Release
    needs: build
    if: startsWith(github.ref, 'refs/tags/v')
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - name: Download All Artifacts
        uses: actions/download-artifact@v4
        with:
          path: release_artifacts

      - name: Generate Checksums
        run: |
          cd release_artifacts
          find . -type f \( -name "*.zip" -o -name "*.tar.gz" \) -exec mv {} . \;
          find . -maxdepth 1 -type d ! -path . -exec rm -rf {} +
          sha256sum * > SHA256SUMS.txt
          cat SHA256SUMS.txt

      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          files: |
            release_artifacts/*.zip
            release_artifacts/*.tar.gz
            release_artifacts/SHA256SUMS.txt
          generate_release_notes: true
          draft: false
          prerelease: false
```

```
minecraft-desktop-v1.0.0-windows-x64/
├── minecraft.exe              # ~2.5 MB statically compiled executable
```

## 7. Local Verification Runbook for Maintainers

Before tagging any release, developers must locally verify binary integrity using native platform tools.

### 7.1. Windows Verification
Run in PowerShell / Developer Command Prompt:
```powershell
# 1. Verify static linkage (No VCRUNTIME or third-party DLLs)
dumpbin /dependents build/minecraft.exe

# Expected Output:
# KERNEL32.dll
# USER32.dll
# GDI32.dll
# OPENGL32.dll
# WINMM.dll
# SHELL32.dll

# 2. Check binary size
(Get-Item build/minecraft.exe).Length / 1MB
# Must report < 4.0 MB
```

### 7.2. Linux Verification
Run in bash terminal:
```bash
# 1. Verify dynamic dependencies
ldd build/minecraft

# 2. Verify glibc symbol version ceilings (must not exceed GLIBC_2.31)
objdump -T build/minecraft | grep -o 'GLIBC_[0-9.]*' | sort -Vu | tail -n 5

# 3. Check stripped binary size
ls -lh build/minecraft
```

### 7.3. macOS Verification
Run in zsh terminal:
```zsh
# 1. Verify universal fat binary slices
lipo -info build/minecraft
# Must output: Architectures in the fat file: build/minecraft are: x86_64 arm64

# 2. Verify framework links
otool -L build/minecraft
```
